\section{Synthesis Reports of the Validated Configurations}
\label{app:synthesis_reports}

This appendix reproduces the Cadence Genus~23.15 reports of the four
E+A+P accelerator configurations that were synthesized to validate the
Level~2 estimates in
Section~\ref{sec:synthesis_validation}
(Table~\ref{tab:talos_estimation_validation}). All designs were mapped
to the TSMC 65~nm low-power standard-cell library
(\texttt{tcbn65lptc}) at the NCCOM corner, 1.2~V and 25~$^\circ$C,
with a 5~ns clock constraint. The reports are included as generated by
the tool; areas are given in $\mu$m$^2$, times in ps and power in W.

For each configuration the following reports are reproduced:

\begin{itemize}
    \item \texttt{qor.rpt}: quality-of-results summary (timing slack,
    instance counts, cell area and run-time information);
    \item \texttt{area.rpt}: area report of the top-level module;
    \item \texttt{gates.rpt}: standard-cell distribution of the mapped
    netlist, grouped by library cell and by cell type;
    \item \texttt{clocks.rpt}: clock definition used for the timing
    analysis;
    \item \texttt{check\_design.rpt}: structural checks of the mapped
    netlist;
    \item \texttt{timing.rpt}: critical path of the design;
    \item \texttt{power/idle.rpt} and \texttt{power/active.rpt}: vectorless
    power estimation for the idle and active scenarios, together with the
    activity annotation used in each case
    (\path{power/*_activity.rpt}).
\end{itemize}

The full timing report lists the worst paths of the design and spans
several thousand lines per configuration; only the first path (the
critical path, from which the maximum frequency is derived) is
reproduced here. Similarly, the SAURIA area report enumerates the
$256$ FP16 processing elements individually, so only the top-level
line is included; the column padding introduced by the long module
names of the omitted per-PE entries is condensed so that the excerpt
fits the page width. This trimming is purely cosmetic: only
whitespace is removed, and no reported value is modified. The
reports reproduced here are stored in the thesis repository under
\path{synthesis_reports/}, one directory per configuration; the
complete synthesis artifacts, including scripts and logs, are kept
with the raw results.
